# Нормалізація тексту

Текст був вибраний зі статей на Wikipedia у випадковому порядку (близько 600т. символів)

Нормалізація за допомогою регулярних виразів
```
import re

CLEAN_PATTERN = re.compile(r'[^а-яё]+')

def normalize_text(text: str) -> str:
    text = text.lower()
    
    text = CLEAN_PATTERN.sub(' ', text)
    
    return text.strip()

with open('Crypto.txt', 'r', encoding='utf-8') as f:
    text = f.read()

normalized = normalize_text(text)

with open('Crypto_normalized.txt', 'w', encoding='utf-8') as f:
    f.write(normalized)

with open('Crypto_normalized_no_spaces.txt', 'w', encoding='utf-8') as f:
    f.write(normalized.replace(' ', ''))
```

Розрахунок ентропії на символ ($H_1$) 

```
import math
from collections import Counter

with open('Crypto_normalized.txt', 'r', encoding='utf-8') as f:
    text = f.read()

frequencies = Counter(text)
total_chars = len(text)

h1 = 0.0

for key in sorted(frequencies.keys()):
    p_i = frequencies[key] / total_chars
    
    h1 -= p_i * math.log2(p_i)
    
print(f"Ентропія H1: {h1:.4f} біт на символ")
```

Результат виконання:
```
Ентропія H1: 4.4316 біт на символ
```

Розрахунок ентропії на символ за біграмною моделлю ($H_2$)

```
import math
from collections import Counter

with open('Crypto_normalized.txt', 'r', encoding='utf-8') as f:
    text = f.read()


bigrams = [text[i:i+2] for i in range(0, len(text)-1, 1)]
total_bigrams = len(bigrams)

bigram_counts = Counter(bigrams)

h_bigram = 0.0

for count in bigram_counts.values():
    p_i = count / total_bigrams
    h_bigram -= p_i * math.log2(p_i)

h2 = h_bigram / 2

print(f"Ентропія H2: {h2:.4f} біт")
```

Результат виконання (з перетинами):
```
Ентропія H2: 4.0346 біт
```

Без перетинів:
```
Ентропія H2: 4.0338 біт
```

# Дослідження впливу розподілу на ентропію

Для експерименту обрано наступні послідовності однакової довжини:

А - нормалізована стаття про фільм "Замок Диявола"
Б - послідовність букви `ы`
В - випадковий набір букв

Передбачаємо наступні ентропії: Б; А; В
Чим рівніше будуть ймовірності кожного символа, тим більша буде ентропія

Випадковий текст був згенерований цим скриптом:
```
import random

ALPHABET = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя "

def generate_max_entropy_text(length):
    return "".join(random.choices(ALPHABET, k=length))

random_text = generate_max_entropy_text(34279)

with open('Task3_random_no_spaces.txt', 'w', encoding='utf-8') as f:
    f.write(random_text)

```

$H_1$ для випадкового набору букв (з пробілами)
```
Ентропія H1: 5.0870 біт на символ
```

$H_1$ для випадкового набору букв (без пробілів)
```
Ентропія H1: 5.0435 біт на символ
```

$H_1$ для натурального тексту (з пробілами)
```
Ентропія H1: 4.4439 біт на символ
```

$H_1$ для натурального тексту (без пробілів)
```
Ентропія H1: 4.4667 біт на символ
```

$H_1$ для послідовності літери `ы`
```
Ентропія H1: 0.0000 біт на символ
```

Результати дослідження збігаються із передбаченням. Для випадкового набору символів ентропія $H_1$  близька до  $H_0 = log_2(n)$, якщо порівняти результати, то похибка мінімальна (що для тексту з пробілами, що без). 
Оскільки пробіл є найчастішим символом мови, то у випадку натуральної мови він забирає на себе найбільшу ймовірність, тим самим "згладжуючи" різницю ймовірностей інших літер, тому ентропія тексту без пробілів дещо вища за ентропію тексту з ними.
Ентропія для послідовності однієї букви нульова, оскільки єдина ймовірність $P(ы)=1$, а $log2(1)=0$, тому $-\sum_{i=1}^{n} p_i*log2(p_i) = 0$

# Дослідження залежностей між символами

Тексти згенеруємо за допомогою цього скрипта
```
import random

alphabet_pattern = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя "
sequence_d = alphabet_pattern * 10000

sequence_g_list = list(sequence_d)

random.shuffle(sequence_g_list)

sequence_g = "".join(sequence_g_list)

with open('Task4_periodic.txt', 'w', encoding='utf-8') as f:
    f.write(sequence_d)

with open('Task4_random.txt', 'w', encoding='utf-8') as f:
    f.write(sequence_g)

```

Прогнозуємо, що ентропії $H_1$ будуть приблизно однаковими, тоді як значень $H_2$ уже буде суттєва різниця. Ентропія $H_2$ має бути меншою у періодичного тексту. Оскільки вибірка біграм з перетинами приблизно у два рази більше, то результати можуть змінитись, але зважаючи на періодичність, ймовірності перерозподіляться, проте будуть такі ж "гладкі" як і для біграм без перетинів

Результати для $H_1$ ідентичні
```
Ентропія H1: 5.0875 біт на символ /// для випадкового тексту
Ентропія H1: 5.0875 біт на символ /// для впорядкованого тексту
```

Результати для $H_2$ з перетинами біграм
```
Ентропія H2: 5.0863 біт /// випадковий текст
Ентропія H2: 2.5437 біт /// впорядкований
```

Результати для $H_2$ без перетину біграм
```
Ентропія H2: 5.0851 біт
Ентропія H2: 2.0437 біт
```

У загальному прогноз збігся, проте ми не очікували таких розбіжностей для $H_2$ впорядкованих текстів.

- Оскільки ентропія $H_1$ не зважає на порядок символів у тексті, а лише на ймовірності конкретних символів, то для рівноможливих появ символів у тексті ентропія буде однакова
- Бо у впорядкованому тексті більшість біграм із випадкового навіть не зустрічаються - передбачувана структура тексту створює піки ймовірностей, що зменшує ентропію
- Модель біграм використовує спільні частоти сусідніх символів, тому розрізняє тексти з однаковими частотами літер, але різними закономірностями їхнього сусідства

# Відповіді до пункту 5

- Значення ентропій не повинні збігатися, оскільки вони отримані для різних моделей джерела. H₁ враховує лише частоти окремих символів, H₂ — частоти сусідніх пар, а H⁽ⁿ⁾ оцінює невизначеність наступного символу за відомого контексту. Також на результати вгадування впливають кількість експериментів і знання мови експериментатором.
- H₁ не враховує порядок символів. H₂ враховує залежності між сусідніми символами через частоти біграм. Для нашого тексту з пробілами H₁ = 4.4316, тоді як H₂ з перетинами = 4.0346 біт на символ. H₂ у цій роботі дорівнює половині ентропії пари, а не умовній ентропії наступного символу.
- Довший контекст дозволяє врахувати будову слів, граматику та зміст речення, тому наступний символ стає простіше передбачити. Для порядків 10 і 20 частка вгадувань з першої спроби становила 0.42, а для порядку 30 — 0.58.
- Зі збільшенням порядку обидві межі ентропії зменшились: для H⁽¹⁰⁾ отримали 2.5961–3.2167, а для H⁽³⁰⁾ — 1.7291–2.4111 біт на символ. Це узгоджується зі зменшенням невизначеності при врахуванні довшого контексту. Водночас інтервали сусідніх порядків перекриваються, тому строгий порядок точних значень ентропії з цих результатів не випливає.

Для H₁ та H₂ використано наш текст, а для H⁽ⁿ⁾ — фрагменти CoolPinkProgram. Алфавіти також відрізняються, тому різниця результатів пов'язана не лише з довжиною контексту.

# Оцінювання надлишковості джерела

Надлишковість розрахуємо за формулою

```
R = 1 - H / H₀
H₀ = log₂(m)
```

де m — кількість символів алфавіту. Замість невідомої ентропії джерела підставляємо отримані H₁, H₂ та H⁽ⁿ⁾, тому для кожної моделі маємо свою оцінку надлишковості.

Для нашого тексту з пробілами алфавіт містить 34 символи, без пробілів — 33. Для CoolPinkProgram приймаємо 32 символи відповідно до таблиці ймовірностей q₁–q₃₂ на скриншотах.

```
H₀ з пробілами: log₂(34) = 5.0875 біт на символ
H₀ без пробілів: log₂(33) = 5.0444 біт на символ
H₀ для CoolPinkProgram: log₂(32) = 5 біт на символ
```

Приклад розрахунку за H₁ для тексту з пробілами

```
R₁ = 1 - 4.43164949 / 5.08746284 ≈ 0.1289 ≈ 12.89%
```

Таблиця надлишковості за частотами символів та біграм

| Оцінка | З пробілами | Без пробілів |
| :----- | ----------: | -----------: |
| За H₁ | 12.89% | 11.57% |
| За H₂ з перетинами | 20.69% | 17.88% |
| За H₂ без перетинів | 20.71% | 17.91% |

Для CoolPinkProgram ентропію отримали у вигляді інтервалу. Оскільки зі збільшенням ентропії надлишковість зменшується, межі обчислюємо у зворотному порядку:

```
Rмін = 1 - Hмакс / H₀
Rмакс = 1 - Hмін / H₀
```

Приклад розрахунку за H⁽¹⁰⁾

```
Rмін = 1 - 3.21669456263237 / 5 ≈ 0.3567 ≈ 35.67%
Rмакс = 1 - 2.59609169269650 / 5 ≈ 0.4808 ≈ 48.08%
```

У розрахунках використано неокруглені значення ентропій; результати у відсотках округлено до двох знаків після крапки.

- Природна мова має ненульову надлишковість, оскільки символи зустрічаються з різними ймовірностями та залежать один від одного. Будова слів, граматика і зміст обмежують можливі продовження тексту. Через це його ентропія менша за максимальну ентропію рівноймовірних незалежних символів того самого алфавіту.
- Чим простіше передбачити наступний символ, тим менша його невизначеність і тим більша надлишковість за однакового алфавіту. Такі закономірності дозволяють стискати текст без втрати інформації. Отримані відсотки характеризують надлишковість моделей, а не фактичний відсоток стиснення файлу конкретним архіватором.

# Аналіз результатів

1. Природна мова має значні статистичні обмеження: букви зустрічаються з різною частотою, існують стійкі залежності між символами. Це тягне розподіл ймовірностей у бік статистично ймовірніших символів (наприклад, пробіл чи буква «о»), що зменшує невизначеність. Натомість випадкова рівноймовірна послідовність не містить жодних залежностей, а всі символи з'являються з однаковою частотою, тому її ентропія наближається до максимально можливої ($H_0 = \log_2(m)$). У нашому експерименті $H_1$ природного тексту склала 4.4439 біт, тоді як для випадкового — 5.0870 біт (що близько до $H_0$).
2. Ентропія $H_1$ розглядає текст як набір незалежних символів і враховує лише індивідуальні частоти їх появи. Ентропія $H_2$ (модель біграм) додатково враховує статистичні зв'язки між сусідніми символами (спільну ймовірність пар). Вона фіксує, які комбінації символів є типовими для мови, а які — неможливими, що дозволяє точніше оцінити реальну невизначеність джерела тексту.
3. Так, безумовно. Це напряму доводить Експеримент 4. Для експерименту було згенеровано два тексти: один із суворою періодичною структурою, а інший — його випадково перемішана копія. Оскільки набір символів та їхня загальна кількість в обох текстах були ідентичними, значення $H_1$ збіглися. Однак значення $H_2$ кардинально відрізнялися: для випадкового тексту $H_2 \approx 5.0863$ біт, а для періодичного $H_2$ знизилась до $2.5437$ біт, оскільки модель біграм виявила закономірність сусідства символів у впорядкованому тексті
4. Вилучення пробілів призвело до незначного **збільшення** ентропії (в Експерименті 2 значення $H_1$ зросло з 4.4316 до 4.4609 біт, а $H_2$ з 4.0346 до 4.1423 біт). Пробіл є найчастішим символом природної мови. Його видалення перерозподіляє загальну ймовірність між іншими, рідкіснішими символами, роблячи їхні ймовірності трохи більш рівномірними ("згладжуючи" загальний розподіл). Чим більш рівномірний розподіл частот, тим вища ентропія.
5. Різниця виникає через обсяг вибірки та повноту врахування природних зв'язків. Метод із перетином збирає всі можливі пари сусідніх символів (всього $N-1$ пар), фіксуючи повну картину закономірностей у тексті. Метод без перетинів зчитує текст блоками по два символи (всього $N/2$ пар), пропускаючи зв'язок між другою літерою однієї пари та першою літерою наступної. Через це другий метод втрачає частину статистичних даних про сусідство символів, що призводить до відхилень (у нашому досліді розбіжність склала лише ~0,02%).
6. Ці оцінки відповідають різним моделям джерела, які враховують різну глибину контексту. $H_1$ та $H_2$ - це ентропії для незалежних символів та для пар. Оцінки $H^{(n)}$ показують невизначеність появи наступного символу за умови знання $n-1$ попередніх. Чим більший контекст нам відомий, тим легше вгадати наступний символ завдяки правилам граматики та лексики. Тому зі збільшенням порядку моделі невизначеність поступово зменшується: від $4.43$ біт для $H_1$ до інтервалу $1.72–2.41$ біт для $H^{(30)}$.
7. **Експеримент 4** (періодичний та випадковий тексти), оскільки він наочно доводить, що ентропія $H_2$ здатна реагувати виключно на зміну порядку символів (залежностей) при незмінних частотах самих символів. **Експеримент 5** (CoolPinkProgram). Він глибше показує, як саме залежності у природній мові впливають на передбачуваність: знання 30 попередніх символів дозволяє вгадувати наступний значно частіше, ніж знання лише 10 символів, що різко зменшує ентропію джерела
8. Зі збільшенням контексту умовна ентропія тексту суттєво зменшується, що свідчить про наявність великої **надлишковості** у природній мові. Надлишковість $R = 1 - H/H_0$ характеризує можливий ступінь ущільнення інформації. У наших результатах надлишковість зростала від ~12% (за моделлю $H_1$) до понад 50-65% (за моделлю $H^{(30)}$). Це означає, що понад половина символів у тексті є структурно "зайвими" (їх можна вгадати за попередніми даними), тому застосування алгоритмів архівації дозволяє ефективно стискати такі тексти без жодної втрати змісту.

# Висновки

Під час виконання комп'ютерного практикуму було проведено комплексне дослідження ентропії та надлишковості джерела відкритого тексту, що дозволило експериментально підтвердити ключові теоретичні положення теорії інформації.

>На основі дослідження нормалізованого російськомовного тексту та згенерованих послідовностей доведено, що найбільшу ентропію має випадковий текст із рівномірним розподілом незалежних символів. Наявність домінуючих символів в природній мові порушує рівномірність розподілу, що призводить до зменшення загальної ентропії $H_1$
> 
> Порівняння моделей джерела довело, що ентропія $H_1$ є лише грубим наближенням. Перехід до біграмної моделі дозволив врахувати закономірності сусідства символів, що суттєво зменшило показник ентропії.
>    
> Експерименти за допомогою CoolPinkProgram підтвердили, що із розширенням контекстного вікна здатність експериментатора передбачати наступний символ зростає. Це призводить до подальшого зниження умовної ентропії джерела
> 
> Зі зменшенням ентропії при врахуванні глибшого контексту, оціночний показник надлишковості тексту зростав. Це практично доводить, що природні мови є сильно надлишковими системами.

Отже, експериментальним шляхом доведено, що реальна ентропія природного тексту значно нижча за максимально можливу, а точність її оцінки прямо залежить від глибини врахованого контексту.
